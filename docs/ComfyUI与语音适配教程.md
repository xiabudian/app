# ComfyUI 与语音适配教程

本 App 支持把 **本地 ComfyUI** 当作生图 / 语音合成引擎：工作流里跑 SD、Flux、IndexTTS 等都行，App 只负责填参数、提交任务、取结果。

## 一、启动 ComfyUI（电脑上）

手机要访问电脑上的 ComfyUI，必须开局域网监听和跨域头，启动命令改为：

```bash
python main.py --listen 0.0.0.0 --port 8188 --enable-cors-header "*"
```

- `--listen 0.0.0.0`：允许局域网设备（手机）访问，默认只允许本机
- `--enable-cors-header "*"`：允许 App（网页/APK）跨域调用接口，**不加必报「Failed to fetch」**
- 电脑防火墙放行 8188 端口；手机和电脑必须连同一个 WiFi
- 启动后命令行会显示本机地址（如 `http://192.168.1.10:8188`），记下来

## 二、App 里配置

「设置 → 通用 → ComfyUI」：

1. **服务器**：填上面的地址，如 `http://192.168.1.10:8188`（结尾不要带 `/`）
2. **导入工作流 JSON**：见下节
3. **工作流名称**：可选，导入前填写；留空则用文件名

## 三、导入工作流

1. 在 ComfyUI 网页里搭好 / 载好工作流
2. 菜单「工作流 → 导出(API)」（注意不是普通「导出」，普通导出的 JSON 无法导入）
3. 得到的 JSON 文件在 App 里导入即可

App 会自动识别类型并做节点绑定：

| 识别依据 | 类型 | 用在哪 |
| --- | --- | --- |
| 有 `SaveAudio` 节点 | 语音工作流 | 「语音」页选 ComfyUI 引擎 |
| 其余（有 `SaveImage`） | 绘图工作流 | 「绘图」页「生成引擎」选它 |

自动绑定规则（节点多于 1 个时，设置页会出现下拉框可手动改）：

- 提示词 → 第一个 `CLIPTextEncode` 节点（生图时填入你的描述；注意正向/负向两个文本框只会填你绑定的那个）
- 参考图 → 第一个 `LoadImage` 节点（图生图）
- 参考音频 → 第一个 `LoadAudio` 节点（音色克隆）
- 所有 `seed` 输入每次执行前自动随机化，避免同提示词命中缓存不出新图

## 四、用 ComfyUI 生图

「绘图」页 → 生成引擎选 `ComfyUI：xxx` → 正常输提示词 / 传参考图 → 生成。

- 比例、步数、模型等**全部由工作流自己决定**，App 里的「比例」选项对 ComfyUI 引擎不生效
- 参考图会自动上传到 ComfyUI 的 input 目录再执行
- 生成走轮询，最长等 10 分钟；结果自动进「作品」页，保存 / 下载与云服务商完全一致

## 五、语音合成

「语音」页两种引擎：

- **在线模型**：跟随「设置 → 对话」当前服务商的地址和 Key，要求服务商支持 OpenAI 兼容 `/v1/audio/speech`（模型名在「设置 → 通用 → 语音」里改，如 `tts-1`）
- **ComfyUI**：选已导入的语音工作流（如 IndexTTS）。工作流里有 `LoadAudio` 节点时可上传**参考音频**做音色克隆；没有则直接合成

生成的音频自动存到手机「下载/AIChat/」（APK），网页端走浏览器下载。

## 六、常见坑

| 现象 | 原因 / 解决 |
| --- | --- |
| 一直「Failed to fetch」 | ComfyUI 没加 `--enable-cors-header "*"`，或服务器地址写错 |
| 手机连不上 | 没加 `--listen 0.0.0.0`、不在同一 WiFi、防火墙拦了 8188 |
| 导入失败「不是 API 格式」 | 用了普通「导出」；必须「导出(API)」 |
| 提示词没生效 | 多文本节点绑错了：到设置页该工作流下换一个「提示词节点」 |
| 每次出的图都一样 | 正常情况下 App 已随机化 seed；若工作流用固定 seed 节点（如 SEED 硬编码在别的类型里），进工作流手动改 |
| 切后台后卡住 | ComfyUI 轮询是断线自动重连的，回前台会继续；最长 10 分钟超时 |
